## About the Lab

**MaduroLabs** is an independent software experimentation lab focused on exploring how software can be designed, built, and executed differently.

We build experimental frameworks, reactive runtimes, AI infrastructure, developer tools, and interactive applications to investigate technical ideas through real implementations.

Our interests span multiple layers of the software stack — from low-level runtime architecture and reactive computation to intelligent development workflows and immersive browser experiences.

Not every experiment needs to become a product. Sometimes, understanding why something works is the most valuable outcome.

#### [Ruseact](https://github.com/MaduroLabs/ruseact)

An experimental React-inspired runtime powered by a Rust reactive core, exploring a different approach to reactivity, state propagation, and rendering without relying on Fiber.

**Research directions**

- Fine-grained reactivity and dependency tracking
- Rust-powered reactive computation

## Engineering Philosophy

We approach software engineering as a continuous process of questioning, experimenting, measuring, and refining.

| Principle | What it means |
| :--- | :--- |
| **Understand before abstracting** | Explore the underlying problem before introducing layers of complexity. |
| **Design intentionally** | Make architectural decisions explicit and evaluate their trade-offs. |
| **Measure, don't assume** | Use benchmarks, profiling, and reproducible experiments to evaluate performance. |
| **Build incrementally** | Develop systems through small, verifiable milestones. |
| **Make correctness a priority** | Treat testing, reliability, and documentation as essential engineering work. |
| **Remain curious** | Question conventional approaches without rejecting proven solutions unnecessarily. |
| **Share the process** | Make experiments, findings, failures, and improvements accessible through open source. |
