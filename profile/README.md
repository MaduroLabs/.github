
# MaduroLabs

**An independent software experimentation lab.**

MaduroLabs is a space for exploring software architecture,
building developer tools, and experimenting with new approaches
to software engineering.

Our projects are driven by curiosity, technical exploration,
and the desire to understand how software works beneath
its abstractions.

## Projects

| Project | Description |
| :--- | :--- |
| [Ruseact](https://github.com/MaduroLabs/ruseact) | An experimental reactive UI framework powered by Rust, WebAssembly, and TypeScript. |
| [Ruseact Example](https://github.com/MaduroLabs/ruseact-example) | A playground for exploring and validating Ruseact in real applications. |
| [StylePort](https://github.com/MaduroLabs/styleport) | A collection of reusable skills for AI-assisted frontend development. |

## Areas of exploration

- Reactive systems and UI frameworks
- Compilers and runtime architecture
- Rust and WebAssembly
- AI-assisted software engineering
- Agent orchestration and workflow execution
- Developer tooling and automation
- Software architecture and performance

## Engineering principles

- Understand the problem before designing the abstraction.
- Make architectural decisions explicit.
- Measure performance rather than assume it.
- Treat testing and documentation as part of engineering.
- Build incrementally and validate continuously.
- Share what we learn through open source.

## Open source

Our public projects are open to technical discussions,
feedback, experiments, and contributions.

Many of these projects are experimental and under active
development. APIs, architectures, and implementation details
may evolve as we learn.
